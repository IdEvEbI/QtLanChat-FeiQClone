### 03-data-types.md - 数据类型详解

#### 🔑 核心知识点

- **整数类型**
  - `int`（4 字节）- 常用整数
  - `short`（2 字节）- 小整数
  - `long`（8 字节）- 大整数
  - `long long`（8 字节）- 超大整数
  - 后缀表示：`L`（long）、`LL`（long long）

- **浮点类型**
  - `float`（4 字节）- 单精度
  - `double`（8 字节）- 双精度（推荐）
  - `long double`（16 字节）- 高精度
  - 后缀表示：`f`（float）、`L`（long double）

- **字符类型**
  - `char`（1 字节）- 单个字符
  - ASCII 码概念
  - 字符用单引号 `'A'`

- **布尔类型**
  - `bool`（1 字节）- 真/假
  - `true` / `false`
  - 输出规则：`true` 输出 1，`false` 输出 0

- **字符串类型**
  - `std::string`（动态长度）
  - `#include <string>` 头文件
  - 字符串拼接：`+` 操作符
  - `.length()` 方法（获取长度）
  - 中文字符 UTF-8 编码（每个中文 3 字节）

- **类型大小**
  - `sizeof()` 操作符
  - 查看各种类型占用的字节数

- **类型转换**
  - 隐式转换（自动转换）
  - 显式转换（强制转换）
  - `static_cast<>()` - 推荐的安全转换方法

- **类型推断**
  - `auto` 关键字
  - `typeid()` - 运行时类型信息（RTTI）
  - `#include <typeinfo>` 头文件
  - 输出类型信息

- **重要概念**
  - 整数范围：`INT_MIN`、`INT_MAX`
  - `#include <climits>` 头文件
  - 时间戳概念（Unix 时间戳介绍）

- **输出格式化**
  - `std::fixed` - 固定小数点表示法
  - `std::setprecision(2)` - 设置小数位数
  - `#include <iomanip>` 头文件

#### 🎓 教学特色

- **类比**：数据类型像不同大小的容器
- **类比**：`sizeof()` 像测量盒子的尺寸
- **类比**：类型转换像单位换算
- **类比**：`auto` 像自动识别物品类型

### 05-if-branch.md - 分支结构详解

#### 🔑 核心知识点

- **单分支（if）**
  - 语法：`if (条件) { ... }`
  - 条件为真时执行
  - 类比：如果...就...

- **双分支（if-else）**
  - 语法：`if (条件) { ... } else { ... }`
  - 两个分支必执行其一
  - 类比：如果...否则...

- **多分支（if-else if-else）**
  - 语法：多个 `else if` 和最后的 `else`
  - 从上到下依次检查
  - 找到匹配后停止
  - 最佳实践：else if 建议不超过 3-5 个

- **嵌套分支**
  - 在 if 或 else 内再嵌套 if-else
  - 嵌套层级建议不超过 2-3 层

- **条件表达式**
  - 条件必须是 `bool` 类型
  - 可以是比较运算或逻辑运算

- **重要规则**
  - else 只能有一个
  - else if 可以有多个
  - 大括号使用建议（始终使用大括号）
  - 执行顺序（从上到下）

- **最佳实践**
  - 避免过深嵌套
  - else if 数量控制
  - 条件过多时考虑 switch（预告）

- **用户输入**
  - `std::cin` 在条件判断中的应用
  - 交互式程序设计

#### 🎓 教学特色

- **类比**：分支结构像交通信号灯
- **类比**：if-else if 像单选题，多个 if 像多选题
- **类比**：嵌套像层层权限验证
