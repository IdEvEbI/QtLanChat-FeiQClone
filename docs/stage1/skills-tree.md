### 05-if-branch.md - 分支结构详解

#### 🔑 核心知识点

- **单分支（if）**
  - 语法：`if (条件) { ... }`
  - 条件为真时执行
  - 类比：如果...就...

- **双分支（if-else）**
  - 语法：`if (条件) { ... } else { ... }`
  - 两个分支必执行其一
  - 类比：如果...否则...

- **多分支（if-else if-else）**
  - 语法：多个 `else if` 和最后的 `else`
  - 从上到下依次检查
  - 找到匹配后停止
  - 最佳实践：else if 建议不超过 3-5 个

- **嵌套分支**
  - 在 if 或 else 内再嵌套 if-else
  - 嵌套层级建议不超过 2-3 层

- **三元运算符（条件运算符）**
  - 语法：`条件 ? 值1 : 值2`
  - 如果条件为真返回 `值1`，否则返回 `值2`
  - 是 if-else 的简化形式，只能用于赋值或返回值
  - 适合场景：简单的双分支赋值
  - 不适合场景：复杂的逻辑判断、需要多行代码的情况
  - 可读性：虽然简洁，但可读性不如 if-else
  - 使用建议：初学者优先使用 if-else，熟练后再使用三元运算符
  - 类比：就像"如果下雨就带伞，否则带雨衣"，用三元运算符就是 `下雨 ? 伞 : 雨衣`
  - 示例：`int max = (a > b) ? a : b;` 等价于 `if (a > b) max = a; else max = b;`

- **条件表达式**
  - 条件必须是 `bool` 类型
  - 可以是比较运算或逻辑运算

- **重要规则**
  - else 只能有一个
  - else if 可以有多个
  - 大括号使用建议（始终使用大括号）
  - 执行顺序（从上到下）

- **最佳实践**
  - 避免过深嵌套
  - else if 数量控制
  - 条件过多时考虑 switch（预告）

- **用户输入**
  - `std::cin` 在条件判断中的应用
  - 交互式程序设计

#### 🎓 教学特色

- **类比**：分支结构像交通信号灯
- **类比**：if-else if 像单选题，多个 if 像多选题
- **类比**：嵌套像层层权限验证
- **类比**：三元运算符像"如果下雨就带伞，否则带雨衣"的简化表达

### 06-while-loop.md - while 循环详解

#### 🔑 核心知识点

- **while 循环基础**
  - 语法：`while (条件) { ... }`
  - 只要条件为真就重复执行
  - 先判断后执行（循环体可能一次都不执行）

- **循环的特点**
  - 条件检查：循环开始前和每次循环结束后都会检查
  - 条件必须改变：避免无限循环
  - 适合不确定次数的重复任务

- **循环变量**
  - 需要在循环外初始化
  - 需要在循环内更新（改变条件）
  - 类比：开车前检查油箱，从起点开始

- **关键规则**
  - 必须有改变条件的语句（如 `count++`、`value--`）
  - 否则会陷入无限循环
  - 类比：忘记关水龙头，水会一直流

- **常见应用场景**
  - 计数循环：从 1 数到 n
  - 用户输入循环：处理持续的用户输入
  - 求和循环：累加数字总和
  - 菜单循环：显示菜单直到用户退出
  - 条件循环：根据布尔值控制

- **无限循环**
  - `while(true)` 的特殊用法
  - 适用场景：事件驱动程序、服务器程序、游戏主循环
  - 必须有退出机制：`break`、`return`、程序退出条件

- **新知识点**
  - `std::cin` 在循环中使用（持续输入）
  - 循环中的条件更新
  - 避免无限循环的最佳实践

#### 🎓 教学特色

- **类比**：while 循环像"只要不下雨就一直散步"
- **类比**：循环变量像计数器
- **类比**：无限循环像卡住的机器

### 07-for-loop.md - for 循环详解

#### 🔑 核心知识点

- **for 循环基础**
  - 语法：`for (初始化; 条件; 更新) { ... }`
  - 初始化、条件、更新都在一行
  - 适合确定次数的重复任务

- **三个部分**
  - **初始化**：循环开始时执行一次，初始化循环变量
  - **条件**：每次循环前检查，为真则继续
  - **更新**：每次循环后执行，改变循环变量

- **for vs while 对比**
  - while：初始化、条件、更新分散在三处
  - for：三个部分集中在一行，更简洁
  - 类比：while 像分散的厨房，for 像一体的工具箱

- **循环变量作用域**
  - 循环变量只存在于循环内部
  - 循环结束后无法访问
  - 类比：在教室里才能用椅子，出教室用不了

- **跳步循环**
  - `i += 2`：步长为 2
  - `i += 3`：步长为 3
  - 跳过某些值

- **倒序循环**
  - `for (int i = 5; i >= 1; i--)`：从 5 到 1

- **嵌套循环**
  - 外层循环控制行，内层循环控制列
  - 总执行次数 = 外层次数 × 内层次数
  - 类比：给教室排座位，外层处理行，内层处理列

- **循环控制语句（break 和 continue）**
  - `break`：立即跳出当前循环（找到目标、错误发生、满足退出条件）
  - `continue`：跳过本次循环的剩余部分（跳过某些值、过滤数据）
  - 类比：break 像"找到想要的，停止搜索"；continue 像"这个不对，下一个"

- **重要规则**
  - 初始化、条件、更新都在 for 括号内
  - 循环变量的作用域仅限于循环内部
  - 可以省略某些部分：`for (; i < 5;)`、`for (;;)`
  - break 和 continue 的使用场景和区别

- **常见应用场景**
  - 计数循环：打印数字序列
  - 倒序循环：倒计时
  - 字符串打印：重复打印文本
  - 跳跃式循环：输出偶数
  - 求和循环：累加计算
  - 嵌套循环：打印表格（如九九乘法表）
  - 循环控制：查找、过滤数据

- **新知识点**
  - 数组初步概念：`std::string users[5]`
  - 数组访问：`users[0]`、`users[1]`
  - 数组索引从 0 开始（0, 1, 2, 3, 4）

#### 🎓 教学特色

- **类比**：for 循环像"从 1 数到 10"（确定次数）
- **类比**：嵌套循环像"给教室排座位"
- **类比**：break 像"找到想要的，停止搜索"
- **类比**：continue 像"跳过这一项，继续下一项"

### 08-switch.md - switch 分支详解

#### 🔑 核心知识点

- **switch 分支基础**
  - 语法：`switch (表达式) { case 值: ... break; default: ... }`
  - 根据表达式的值从多个选项中选择执行
  - 类比：自动售货机，按不同按钮得到不同商品

- **组成部分**
  - **switch 表达式**：必须是整数类型或枚举类型
  - **case 标签**：每个 case 后面跟常量值，不能使用变量
  - **break 语句**：跳出 switch，避免 case 穿透
  - **default 分支**：可选，处理所有 case 都不匹配的情况

- **case 穿透**
  - 多个 case 之间没有 break 会一起执行后续代码
  - 故意的穿透：多个值共享同一段代码
  - 意外的穿透：忘记写 break（常见错误）
  - 类比：多个按钮对应同样的功能

- **重要规则**
  - **表达式类型限制**：只能是整数类型或枚举类型
    - 正确：`switch (choice)` - choice 是 int
    - 正确：`switch (grade)` - grade 是 char
    - 错误：`switch (str)` - str 是 std::string
  - **case 标签必须是常量**：不能使用变量
    - 正确：`case 1:`、`case 2:`、`case 'A':`
    - 错误：`case i:`（i 是变量）
  - **break 的必要性**：每个 case 后面通常要有 break
  - **类比**：switch 像电梯按钮，按下楼层号跳转到对应楼层

- **switch vs if-else if**
  - switch：适合离散的固定值（菜单选项、状态码、等级）
  - if-else if：适合范围值或复杂条件（分数区间、组合条件）
  - 选择原则：离散固定值用 switch，范围或复杂条件用 if-else if

- **常见应用场景**
  - 菜单选择：根据用户输入执行不同功能
  - 状态机：根据状态执行不同操作
  - 成绩等级：将分数转换为等级
  - 消息类型处理：根据消息类型执行不同处理
  - 选项处理：字符或数字选择

- **新知识点**
  - **枚举类型提示**：将在后续详细讲解，非常适合与 switch 配合使用
  - **状态机概念**：根据不同的状态执行不同的处理

#### 🎓 教学特色

- **类比**：switch 像自动售货机
- **类比**：case 穿透像"多个按钮对应同样功能"
- **类比**：break 像"路标，有路标就停下"
- **类比**：switch vs if-else if 像"单选 vs 范围选择"
